1. MEDIDAS DE SEGURIDAD IMPLEMENTADAS (13 controles)
------------------------------------------------------------
  [CSP  ] Content-Security-Policy             — Restringe fuentes de scripts, estilos e imágenes
  [HSTS ] Strict-Transport-Security           — Fuerza HTTPS (activado solo en producción)
  [XFO  ] X-Frame-Options: DENY               — Previene clickjacking
  [CTO  ] X-Content-Type-Options: nosniff     — Evita MIME-type sniffing
  [RP   ] Referrer-Policy                     — Controla información de referrer en navegación
  [PP   ] Permissions-Policy                  — Deshabilita APIs innecesarias del navegador
  [COOP ] Cross-Origin-Opener-Policy          — Aísla el contexto de navegación
  [CORS ] Cross-Origin Resource Sharing       — Restringe acceso a orígenes autorizados
  [RL   ] Rate Limiting                       — 60 req/min por IP en /api/leads
  [CSRF ] CSRF Token                          — Token por sesión + SameSite=Strict
  [SAN  ] Input Sanitization                  — Strip HTML, caracteres de control, límites de longitud
  [VAL  ] Validación server-side              — Email RFC 5322, nombre >= 2 chars, teléfono >= 7 dígitos
  [HON  ] Honeypot anti-spam                  — Campo oculto _hp_field para detectar bots

2. CAPA DE DATOS — ROW LEVEL SECURITY (Supabase PostgreSQL)
------------------------------------------------------------
  Roles definidos: anon, authenticated, service_role
  Políticas RLS: 11 políticas en 4 tablas

  Tabla leads:
    - anon: solo INSERT (formulario landing page)
    - authenticated: SELECT + UPDATE (dashboard y ventas)
    - service_role: bypass total (pipeline n8n)

  Tabla lead_events:
    - authenticated: SELECT (consulta de trazabilidad)
    - append-only: sin políticas UPDATE ni DELETE

  Hashing de PII:
    - SHA-256 de email y teléfono para búsqueda interna
    - ATENCIÓN: SHA-256 sin salt NO constituye anonimización
      criptográfica. Funciona como campo auxiliar de búsqueda.
    - Los datos originales (email, teléfono) se conservan en la tabla
      para el funcionamiento del sistema (envío de emails).
    - IP anonimizada mediante máscara /16 (IPv4) o /48 (IPv6)
