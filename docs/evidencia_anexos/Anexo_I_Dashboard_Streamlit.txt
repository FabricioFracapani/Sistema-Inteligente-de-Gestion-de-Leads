========================================================================
ANEXO I — EVIDENCIA DEL DASHBOARD DE VENTAS (Streamlit)
========================================================================

CARACTERISTICAS DEL DASHBOARD:
--------------------------------------------------
  - Framework: Streamlit 1.40.0 (pinneado en dashboard/requirements.txt)
  - Conexion: Supabase PostgreSQL via supabase-py 2.7.0
  - Puerto: 8501 (localhost)

KPIs EN TIEMPO REAL (5 metricas, extraidas de dashboard.py):
--------------------------------------------------
  1. Total Leads
  2. 🔥 Compra Inmediata
  3. ℹ️ Solicita Info
  4. 🚫 Spam Detectado
  5. ⭐ Prioridad Promedio

FILTROS DISPONIBLES (extraidos de dashboard.py):
--------------------------------------------------
  1. Rango de fechas (desde/hasta, default: ultimos 7 dias)
  2. Clasificación IA (multiselect: compra_inmediata, solicita_info, soporte, spam)
  3. Estado (multiselect: nuevo, contactado, en_negociacion, ganado, perdido, spam)
  4. Prioridad mínima (IA) (slider: 0-100, default: 30)
  5. Fuente (multiselect: landing_page, meta_ads, wordpress, test_100_v3)

VISTA DETALLADA DE LEAD:
--------------------------------------------------
  - Nombre completo, email, fuente, estado
  - Clasificacion IA, prioridad, resumen generado por IA
  - Mensaje original del lead (truncado a 120 caracteres en la tarjeta)
  - Boton 'Ver' para inspeccionar el lead seleccionado

CODIGO DE COLORES POR CLASIFICACION (color_map real del codigo):
--------------------------------------------------
  - compra_inmediata: Rojo
  - solicita_info: Azul
  - soporte: Naranja
  - spam: Gris

RENDIMIENTO:
--------------------------------------------------
  - Cache de datos: 30 segundos (@st.cache_data(ttl=30))
  - Limite de consulta: 200 leads (.limit(200) en la query a Supabase)
  - Diseno responsive con CSS personalizado (gradientes en las tarjetas KPI)

NOTA: Para obtener una captura de pantalla del dashboard:
  1. Ejecutar: cd dashboard && streamlit run dashboard.py
  2. Abrir http://localhost:8501 en el navegador
  3. Tomar captura de pantalla completa
